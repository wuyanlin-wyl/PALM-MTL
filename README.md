# PALM-MTL

Minimal code release for the paper's five-fold PALM multi-task experiments (classification, lesion segmentation, and VQA).

## Status of bundled data

This code release contains no PALM images, masks, labels, or fold manifests. Obtain PALM from its official source and place the files under `data/PALM/` using the layout below. Dataset files are ignored by `.gitignore` so local copies will not accidentally be added to a code commit.

Expected local layout after obtaining the dataset:

```text
data/PALM/
├── train/                   # PALM training images, masks, and task lists
├── valid/                   # PALM validation images, masks, and task lists
├── all_images/              # generated by split_folds.py
├── all_masks/               # generated by split_folds.py
└── folds/fold{0..4}/        # generated train/val/test manifests
```

Generate the folds and unified image/mask links locally with:

```bash
python split_folds.py --data_root ./data/PALM --n_folds 5 --seed 66
```

The generated fold manifests refer to image and mask basenames in `all_images/` and `all_masks/`.

## Setup

Python 3.10+ with PyTorch and a CUDA-capable GPU is recommended. Install the dependencies in `requirements.txt`. Install a PyTorch build matching your CUDA runtime from the official PyTorch instructions.

The tokenizer vocabulary files needed by this implementation are included in `vqa/bert-medvqa/`; no pretrained BERT weights are bundled. The encoder uses the SAM ViT-B checkpoint if `SAM/sam_vit_b_01ec64.pth` is present. That checkpoint is not bundled; without it, the code initializes the encoder without SAM pretraining, so obtain the official checkpoint for paper reproduction. See `THIRD_PARTY_NOTICES.md` for third-party licensing notes.

## Train and evaluate

From this directory, after obtaining PALM and generating the folds:

```bash
python train_GLSA_LoRA_SAM.py --gpus 0 --fold 0 \
  --data_root ./data/PALM --image_path all_images --mask_path all_masks \
  --epochs 100 --batch_size 60 --output_dir ./outputs/fold0
```

Run folds 0–4 with the same command, changing `--fold` and `--output_dir`. Summarize results with:

```bash
python aggregate_results.py --cv_dir ./outputs --n_folds 5
```

Use `--limit 8 --epochs 1 --batch_size 4` for a small pipeline check once the required data and tokenizer are available.
