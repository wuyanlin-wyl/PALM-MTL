# Third-party code and assets

This repository draft contains code adapted from Meta's Segment Anything Model (SAM) implementation in `SAM/modeling/`. Preserve the upstream copyright and license terms when redistributing. The upstream source is available at https://github.com/facebookresearch/segment-anything and is distributed under its Apache-2.0 license; include the complete upstream license text and attribution before public release.

The `vqa/VisualBertResMLP.py` and `vqa/VisualBertResMLPClassification.py` modules identify themselves as adapted from the Hugging Face VisualBERT implementation and Surgical-VQA. Verify and include the exact upstream license and attribution applicable to the modified source before publishing.

The pretrained SAM checkpoint and any tokenizer/model weights are not bundled. Obtain them from their official sources and follow their respective licenses. PALM dataset images and masks are also not included in this draft; confirm public redistribution permission with the dataset authors before adding them.
